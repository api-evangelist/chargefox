# Chargefox

> Chargefox is Australia's largest public electric-vehicle charging network and, since 2023, a charging software platform rather than a hardware owner. Founded in 2017, headquartered in Melbourne, and owned outright since 2022 by Australian Motoring Services — the joint vehicle of six state motoring clubs (NRMA, RACV, RACQ, RAA, RAC, RACT). It publishes two API surfaces: a small, documented, read-only Fleets API described by OpenAPI 3.0.1, and a full Open Charge Point Interface (OCPI) Charge Point Operator implementation across protocol versions 2, 2.1.1, 2.2 and 2.2.1. Both are entirely closed — every endpoint returns 401 to an anonymous request, there is no self-service signup, no sandbox and no developer key. Chargefox publishes zero open market data: no anonymous locations feed, no tariff feed, no network-status feed. This file was generated by API Evangelist from the provider's own public documentation; Chargefox does not publish an llms.txt.

## What an agent needs to know first

- There is no way to get a credential without a commercial relationship. Fleet customers request a bearer token from fleetsupport@chargefox.com. Roaming partners exchange OCPI Token credentials after signing a roaming agreement.
- The entire public REST contract is GET-only. Nothing here creates, updates or deletes anything.
- Rate limits are tight and published per endpoint — 18 requests / 15 minutes on usage and sessions. Honour `X-RateLimit-Reset` and cache aggressively.
- The Australian Consumer Data Right does not apply. Chargefox is not on the ACCC CDR Register (checked 2026-07-27); it operates charge points rather than holding a retail electricity licence.

## APIs

- [Chargefox Fleets API](https://app.chargefox.com/developers/docs/fleets): Four read-only GET operations for fleet customers — usage, sessions, vehicles, invoices. OpenAPI 3.0.1, bearer auth, page-number pagination at 100 records per page. Base URL https://app.chargefox.com/api/fleets/v1
- [Chargefox OCPI CPO API](https://app.chargefox.com/developers/docs/rate_limits): OCPI Charge Point Operator implementation covering locations, sessions, CDRs, tariffs, tokens and commands. Base path https://app.chargefox.com/ocpi/cpo. No specification document is published by Chargefox; the endpoint inventory is documented only in its rate-limits page.

## Operations (Fleets API)

- `GET /api/fleets/v1/usage` — every charge session completed by a fleet's managed vehicles anywhere on the Chargefox network, with per-charging-period consumption, tariff, GST and AUD amount. Params: date_from, date_to, page.
- `GET /api/fleets/v1/sessions` — every charge session completed on a fleet's own charge stations, with the site-host revenue/cost/GST split. Params: date_from, date_to, page.
- `GET /api/fleets/v1/vehicles` — the fleet's managed-vehicle register: VIN, registration, contract number, effective dates, attached RFID cards. Params: page.
- `GET /api/fleets/v1/invoices` — fleet and site-host invoices with line items, billed vehicles and the charge sessions behind them. Params: date_from, date_to, page.

## What does not exist

Recorded so an agent does not waste calls looking: no SDKs in any package registry, no CLI, no Postman collection, no MCP server, no GraphQL endpoint, no AsyncAPI or documented webhooks, no `/.well-known/` documents of any kind (no security.txt, no OAuth or OIDC discovery), no sandbox, no changelog, no public pricing page for API access, and no OAuth — authentication is an opaque bearer token for Fleets and an OCPI Token for roaming.
